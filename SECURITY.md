| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

We take the security of our tools and your local development environment seriously. Because `agent-collab-controller` executes scripts on local workstations with user privileges, responsible vulnerability reporting is critical.

### How to Report

Please **do not report security vulnerabilities through public GitHub issues**.

Please report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/sayne-net/agent-collab-controller/security/advisories/new).

Alternatively, you may contact the maintainer directly:
- **Email**: `sasayne@yahoo.com`
- **GitHub Profile**: [@sasayne](https://github.com/sasayne)

### What to Include

When submitting a report, please include:
- A description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept demonstrating the behavior.
- Affected OS version, PowerShell version, and controller version.

We will review your submission promptly and coordinate a fix and release.
